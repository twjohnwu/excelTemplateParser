# wiki — excelTemplateParser

本目錄收錄與 excelTemplateParser 專案相關、跨功能可重用的知識文件，供 STDD
各階段（尤其是 uiux 階段）在動手設計前先查閱，避免重複推導已存在的慣例。

## 固定分類（taxonomy）

- `design_guideline/` — 設計系統與 UI 慣例（token、字級、互動狀態等）
- `reference/` — 一般參考資料；**不確定歸類時的預設分類**
- `standard/` — 團隊/專案規範
- `coding_standard/` — 程式撰寫規範
- `knowhow/` — 實作技巧與踩坑紀錄
- `cases/` — 具體案例紀錄

## 路由表

| 路徑 | 一句話說明 |
|---|---|
| `design_guideline/frontend-ui-conventions.md` | 從現行 frontend 程式碼萃取的 UI 設計慣例（token、字級、互動狀態、點擊區、對比度、語意色、i18n、既有元件、空狀態） |
